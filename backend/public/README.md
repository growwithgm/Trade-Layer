# TradeLayer Frontend

Static multi-page frontend prototype for the TradeLayer Shopify B2B SaaS app.

## Pages included
- Dashboard
- Activity
- Price Lists
- Price Editor
- Discounts
- Customer Groups
- Sales Agents
- Quick Order
- Companies
- Company Users
- Approvals
- Quotes
- Finance
- Analytics
- Integrations
- Catalog Visibility
- Login Rules
- Contracts
- Settings

## Notes
- Frontend only
- Shared design system across all pages
- Mock data only
- Open `index.html` in a browser to start
